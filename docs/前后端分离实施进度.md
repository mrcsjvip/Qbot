## 📝 使用说明

### 1. 安装依赖

```bash
pip install -r qbot/api/requirements.txt
```

### 2. 启动服务

```bash
python qbot/api/run.py
```

### 3. 访问API文档

- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

### 4. 测试回测API

参考 `qbot/api/TEST.md` 文件
